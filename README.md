# 明和商会 社有車ログ

社有車の「使用開始」「返却」をスマホでタップして記録するWebアプリ。
Mattermost「車両管理」チャンネルにピン止めしたリンクから開いて使う。

## 構成

| 役割 | 使うもの | 場所 |
|---|---|---|
| 画面 | GitHub Pages | `index.html` / `config.js` |
| 受け付け窓口 | Google Apps Script | `gas/Code.gs`（スプレッドシートに貼り付けて使う） |
| 記録の保存先 | Google スプレッドシート | 「使用者」「車両」「ログ」の3シート |

- 社員はログイン不要。ピン止めリンクの `#` の後ろに付けた合言葉が、初回タップ時にスマホへ自動保存される。
- 合言葉はリポジトリに書かない（Apps Script のスクリプトプロパティにだけ保存）。
- 使用者・車両の追加削除はスプレッドシートを直接編集する（30秒以内にアプリへ反映）。

## 運用メモ

- 合言葉が外部に漏れたら：Apps Script エディタで `resetPasskey` を実行 → 新しいリンクを Mattermost に貼り直す。
- `gas/Code.gs` を変更したら：Apps Script に貼り直し →「デプロイ → デプロイを管理 → 編集 → 新バージョン」で更新（URLは変わらない）。
- 変更は feature ブランチで作業し、main へはプルリクエスト経由でマージする。
- 画面（index.html）を変えたら、`index.html` の `APP_VERSION`・`config.js?v=`・`version.json` の版番号を同じ値に上げる。社員のスマホが開いたときに自動で新しい版へ切り替わる（画面下の `ver.` で確認できる）。
