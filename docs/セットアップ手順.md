# 社有車ログ セットアップ手順

所要時間：全部で15分ほど。会社の Google アカウントでログインしたパソコンで作業する。

---

## A. スプレッドシートと Apps Script（約5分）

1. Google ドライブで **新規 → Google スプレッドシート** を作り、名前を「**社有車ログ**」にする。
2. メニューの **拡張機能 → Apps Script** を開く。
3. 最初から入っている `function myFunction() {…}` をすべて消し、`gas/Code.gs` の中身を全部貼り付ける。**Ctrl + S** で保存する。
4. 画面上部の関数の選択欄で **`setup`** を選び、**▷ 実行** を押す。
   - 「承認が必要です」と出たら **権限を確認 → 自分のアカウントを選ぶ → 許可**。
   - 「このアプリは Google で確認されていません」と出た場合は **詳細 → 社有車ログ（安全ではないページ）に移動 → 許可**。自分で作ったスクリプトなので問題ない。
5. 下の実行ログに **`合言葉：xxxxxxxxxxxxxxxx　管理者コード：123456`** と表示される。両方メモする（**チャットには貼らない**）。
   - 合言葉：Mattermost のピン止めリンクに使う
   - 管理者コード（6桁）：社員のスマホの名前登録を解除するときに使う。管理者だけが知っておく
6. スプレッドシートに戻ると「使用者」「車両」「ログ」「端末」の4シートができている。
   - **使用者**：A列に社員の名前を1行ずつ（2行目から）
   - **車両**：A列に車種、B列にナンバー（任意）。同じ車種が複数ある場合は「プロボックス①」「プロボックス②」のように名前を分ける
     - C列「点検予定日」（例 `2026/11/5`）、D列「車検予定」（例 `2027/3`）、E列「お知らせ」（例 `給油必要`）は任意。入れるとアプリの車両カードに表示される。点検は1週間前・車検は前月からオレンジ色、車検月を過ぎると赤で表示。点検日を過ぎた表示は自動で消える
     - F列「給油メモ」は、返却時に「ガソリン少なめ」をチェックするとアプリが自動で書き込む（例 `10/27 山田さんが報告`）。次の人がチェックを外して返却すると消える。手で消してもよい
   - **ログ**：アプリが自動で書き込む。手で編集しない
   - **端末**：社員がスマホを本人専用に登録した記録。アプリが自動で書き込む
7. Apps Script の画面に戻り、右上の **デプロイ → 新しいデプロイ**。
   - 歯車アイコン → **ウェブアプリ**
   - 説明：`社有車ログ`
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - **デプロイ** を押す
8. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）をコピーする。
   - この URL を Claude に伝える → `config.js` に設定する。
   - URL をブラウザで開いて「社有車ログ API は動いています」と出れば成功。

> **「全員」が選べない場合**：Google Workspace の管理者設定で外部公開が制限されています。Claude に伝えてください。

## B. GitHub リポジトリ（約5分）

1. GitHub にログインし、右上の **＋ → New repository**。
   - Repository name：`meiwa-car-log`
   - **Public**（無料プランで GitHub Pages を使うため。合言葉やパスワードはコードに含まれない）
   - **Add a README file にチェック**（main ブランチを作っておくため）
   - **Create repository**
2. 作成したリポジトリの URL（`https://github.com/○○/meiwa-car-log`）を Claude に伝える。
3. Claude が feature ブランチをプッシュする。初回だけ GitHub のログイン画面が出るのでログインする。
4. GitHub に **Compare & pull request** の黄色い帯が出るので、内容を確認して **Create pull request → Merge pull request**。
5. リポジトリの **Settings → Pages**。
   - Source：**Deploy from a branch**
   - Branch：**main** / **/(root)** → **Save**
6. 1〜2分待つと、上部に `https://○○.github.io/meiwa-car-log/` と表示される。

---

## C. Mattermost にピン止め（約2分）

1. ピン止め用のリンクを作る。**ページの URL の後ろに `#` と合言葉を付ける。**

   ```
   https://○○.github.io/meiwa-car-log/#（A-5でメモした合言葉）
   ```

2. 「車両管理」チャンネルに投稿してピン止めする。投稿文の例：

   > 🚗 社有車を使うとき・返すときはこちら → （上のリンク）
   > 名前と車を選んで、ボタンを1回押すだけです。

3. 自分のスマホでリンクをタップし、使用開始 → 返却 → 取り消すが動くか確認する。

> 社員は最初の1回だけピン止めリンクから開けば、2回目以降はブラウザの履歴やホーム画面から開いても使える。
> 合言葉が漏れた場合は、Apps Script で `resetPasskey` を実行し、新しい合言葉でリンクを作り直してピンを差し替える。
